# mutou-humanizer

一个用于中文写作的去 AI 味 Skill。先读你的风格样本，再写初稿，最后按禁令表逐条审校。适合公众号文章、口播稿和日常文案。

它会建立一份保存在你本地的风格基线，记录你的句长、段落、称呼、标点和常用表达。你改过的定稿可以继续补进样本，确认过的新偏好也能写回规则。

## 可以怎么用

| 场景 | 做什么 |
|---|---|
| 写新稿 | 根据素材和风格样本写稿，再逐条自查 |
| 改稿 | 调整已有文案的表达，不添加原文没有的事实 |
| 只审稿 | 标出问题、对应规则和修改建议，不改写全文 |
| 更新风格 | 对比你修改后的定稿，确认后更新本地风格基线 |

审校先通读，再搜词，最后检查结构和具体信息。搜到词以后还会排除误报，不直接把关键词全部删掉。

## 禁令库梗概

内置禁令库覆盖五类常见的 AI 写作痕迹：

| 类别 | 主要检查什么 |
|---|---|
| 词语 | 无信息的过渡和强调、书面连接词、夸张词、商业黑话，以及反复出现的自我判断前缀 |
| 句子 | 先否后肯的套路、抽象拟人、用比喻代替解释、单字和短语压缩意思，以及中文翻译腔 |
| 表达和标点 | 只预告不讲内容的开场、装饰性引号、破折号，以及正文中过多的冒号 |
| 结构 | 重复总结、凑三点和排比、结尾升华与号召、段尾金句，以及过于整齐的段落 |
| 具体度 | 空泛段落、没有来源的数据和案例、编造的亲身经历，以及缺少真实细节的表达 |

每条规则都说明为什么要查、允许出现多少次、有哪些变体、哪些情况不算，以及具体怎么改。检查时先结合上下文排除误报，再按次数上限修改；缺少事实或个人经历时标记【补】，不编造内容。

完整规则和搜索词表见 [SKILL.md 的默认禁令表](SKILL.md#附录默认禁令表)。初始化后可以在自己的 `banlist.md` 里调整，也可以合并已有禁令。

## 安装

仓库根目录的 [SKILL.md](SKILL.md) 包含完整流程、风格档案模板和默认禁令表，没有额外运行依赖。搜词步骤使用 `awk`、`grep` 和 `sed`；环境不支持命令时，技能会要求逐类人工检查。

在使用默认技能目录的 Codex 中，可将整个仓库放到 `~/.codex/skills/mutou-humanizer`：

```bash
git clone https://github.com/itszuo/mutou-humanizer.git ~/.codex/skills/mutou-humanizer
```

如果你自定义了 `CODEX_HOME`，请放到该目录下的 `skills/mutou-humanizer`。安装后，在能发现该技能的新会话中调用。

使用其他支持 `SKILL.md` 的工具时，把仓库放进该工具指定的技能目录，或按其方式导入。不同工具的技能发现方式可能不同。

## 第一次使用

可以直接说：

```text
用 $mutou-humanizer 初始化我的写作风格基线。
```

准备一个可以写入的本地文件夹、写作身份、目标平台与常见篇幅，以及 3 到 5 篇你满意的完整文案。样本不足也能开始，后续可用定稿补充。已有禁令表可以一并合并。

技能会生成以下文件，并请你确认风格档案：

```text
你的基线目录/
├── 去ai味-风格档案.md
├── banlist.md
├── samples/
└── 修改记录.md
```

基线放在你自己的本地目录，不要把私人样本或未发布稿件提交到公共仓库。

## 调用示例

```text
用 $mutou-humanizer 帮我写一篇口播稿。下面是素材……
```

```text
用 $mutou-humanizer 把下面这段改得自然一些，只改表达，不补事实。
```

```text
用 $mutou-humanizer 审查这篇稿子，只列问题和建议，不改写全文。
```

```text
这是我改好的定稿。用 $mutou-humanizer 对比改动，列出可以更新进风格基线的偏好。
```

## 调整规则

默认禁令表针对一种写作身份：做过实事的人，把自己的经验平视地分享给同样在做事的朋友。它是可调整的风格偏好，不是所有中文写作都必须遵守的标准。

初始化后，修改本地基线里的 `banlist.md`。用户自己的规则优先；增加规则时，同时补上编号、理由、上限、例外和改法，并同步搜索词表。

技能用于改进表达，不提供 AI 文本检测，也不承诺任何检测分数。数据、引用和亲身经历仍须有来源；缺少素材时使用【补】标记。
